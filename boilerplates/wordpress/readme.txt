== Installation ==

1. Install via **Plugins → Add New** and search for *Plugin SDK Starter*,
   or upload the .zip via **Plugins → Add New → Upload Plugin**.
2. Activate **Plugin SDK Starter** under **Plugins → Installed Plugins**.
3. Configure under **Settings → Plugin SDK Starter**.

== Frequently Asked Questions ==

= Does this work with multisite? =

Yes. Network-activate or activate per-site.

= Does it call home / send telemetry? =

No. All data stays on your own WordPress site.
